# Art by Mukesh — Website

Responsive static website built with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — layout, colours and responsive styling
- `script.js` — mobile navigation, product filters and footer year

## Before publishing
1. Replace sample product names, descriptions and emoji visuals with the actual products, photographs and details.
2. Replace `hello@artbymukesh.com` in `index.html` with the brand's real email address.
3. Update the About section to reflect Mukesh's actual story.

## Run locally
Open `index.html` in a browser.

## Deploy
Push all website files to a GitHub repository. In Vercel, choose **Add New → Project**, import the GitHub repository, and click **Deploy**. No build command or framework preset is required for this static website.
